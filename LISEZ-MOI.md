# KIRAN EXPRESS — version « téléphone » (tous les fichiers dans un seul dossier)

Mise en ligne depuis un téléphone Android :
1. Décompressez ce ZIP : vous obtenez 97 fichiers dans un seul dossier, sans sous-dossiers.
2. Dans Chrome, ouvrez github.com/kiran-express/kiran-express.github.io
   (menu ⋮ → cochez « Version pour ordinateur »).
3. Add file → Upload files → choose your files → sélectionnez TOUS les fichiers du dossier.
4. Commit changes. Le site est en ligne 1 à 2 minutes plus tard sur https://kiran-express.github.io

Formulaires : collez votre adresse Formspree dans config.js (champ formEndpoint).
Le fichier .nojekyll est caché sur certains téléphones : s'il manque, le site fonctionne quand même.
